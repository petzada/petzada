# Oi, eu sou o Marcio 👋

Desenvolvedor de software em São Paulo e estudante de **Análise e Desenvolvimento de Sistemas**. Por aqui me chamam de **petzada**.

Construo produtos web de ponta a ponta, do banco de dados ao deploy, principalmente para pequenos negócios: agendamento e assinaturas, controle de estoque, delivery, automação de ofertas e sites institucionais.

Programo desde janeiro de 2025, mas a paixão por computação vem de criança: eu ainda não tinha computador e esperava meu irmão ir para a escola para poder mexer no dele.
